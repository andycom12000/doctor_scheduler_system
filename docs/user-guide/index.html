醫師值班排班系統　使用者說明

給排班者看的操作說明。不需要懂電腦技術，也不需要網路。畫面頂部右側會顯示目前的版本號（例如 v1.0.0）。

1. 第一次開啟

放在哪裡

收到的是一個 zip 檔。請解壓到你有權限寫入的位置，例如桌面、文件，或 D:\ 底下的資料夾。

不要放在 C:\Program Files\ 底下。程式會把所有資料寫在自己旁邊的 data 資料夾，放在受保護的位置會無法啟動。

解壓前先解除封鎖（建議）

從網路或電子郵件下載的 zip，Windows 會把裡面所有檔案都標成「來自網際網路」，之後每個檔案都可能被擋。先在 zip 上解除封鎖，可以少很多麻煩。

  1. 在 zip 檔上按滑鼠右鍵，選「內容」。
  2. 在「一般」分頁最下面，勾選「解除封鎖」。
  3. 按「確定」。
  4. 再對 zip 按右鍵，選「全部解壓縮」。

如果「內容」視窗裡沒有「解除封鎖」這個選項，表示檔案沒有被標記，直接解壓縮即可。

啟動程式

  1. 開啟解壓後的資料夾。
  2. 連按兩下 HospitalScheduler.exe。
  3. 第一次啟動可能要等幾秒。

出現「Windows 已保護您的電腦」

這個程式沒有向微軟購買簽章，所以第一次執行時 Windows 可能會跳出藍色的警告視窗。這是正常的，不代表檔案有問題。

  1. 在視窗上按「其他資訊」。
  2. 按下出現的「仍要執行」。

同一個資料夾的同一支程式，通常只會問這一次。

這一段的視窗文字尚待實機確認，不同版本的 Windows 實際畫面可能略有不同；照著「其他資訊」「仍要執行」的意思找按鈕即可。

2. 從零到產出班表

第一次使用，請照下面的順序做。畫面頂部有六個分頁：排班主表、區域與點數、資格與約束、變體比較、不可排班日登記、人員維護。

步驟 1　確認區域與額度點數（「區域與點數」分頁）

  1. 看一下 5 個區域（A、B、C、ICU、總值）是否正確。每區每日固定 1 人，這一段只能看、不能改。
  2. 確認每個身分的額度點數上限。平日班算 1 點，假日班（週六、週日與國定假日）算 2 點，補班日視為平日、算 1 點。額度點數上限是硬上限，不能超過。
  3. 某個月需要不同的額度點數上限時，用「指定月份覆寫」改那個月，改完按「儲存」。目前只有 R6 這一列有「指定月份覆寫」的輸入框。
本系統有兩套完全不同的點數：額度點數有上限、不能超過；公平性點數沒有上限，只用來讓大家盡量公平。這一頁兩套都看得到，請不要混在一起看。

步驟 2　確認資格與約束（「資格與約束」分頁）

  1. 看每個身分可以值哪些區域類型（資格矩陣）。
  2. 看硬約束與軟約束。硬約束一定要遵守；軟約束是「盡量」，可以調整權重或關閉。
  3. 出廠值已經設好。沒有特別需求就不必改；改了要按「儲存」。

步驟 3　確認行事曆的國定假日

國定假日資料來自行政院人事行政總處「政府行政機關辦公日曆表」（政府資料開放平台，依政府資料開放授權條款提供）。程式內建 2026、2027 兩年，之後不用自己輸入：每次開啟程式，只要電腦連得上網，就會自動檢查並更新今年與明年的行事曆（國定假日、補假、補班日）。更新期間畫面會出現「正在更新行事曆…」的遮罩，這段時間無法操作（通常只要幾秒鐘，請稍候）；有實際更新時，畫面會跳出一句「已更新 ○○○○ 年行事曆」；如果變動影響到已發布的月份（變動日所在的月份與它的前一個月），會多提醒「已發布月份的額度點數或公平性點數可能改變」，請回頭確認那些月份的點數看板。官方來源無法連線時，程式會改用社群維護的鏡像（個人維護、非官方），鏡像只會新增或修正日子、不會刪除任何一天。官方通常在每年年中公告隔年的日曆，公告之前抓不到那一年是正常的。國定假日會影響兩件事：哪幾天是假日（週六、週日與國定假日，決定額度點數算 1 點或 2 點，也決定公平性點數查哪一列），以及「連值兩個週六」的加分規則。

目前還沒有可以檢視或修改國定假日的畫面。更新失敗時遮罩會變成說明畫面，分兩種情況（畫面會照實說明哪些年份已更新、哪些失敗）：
  • 已取得官方資料、但寫入失敗（少見，例如磁碟問題）：畫面只有「重試」，要重試成功才能繼續使用；會說明哪一年寫入失敗、哪些年份已更新。若一直失敗，請把 data/calendar-sync.log 交給維護者。
  • 取不到可用的資料（離線、醫院網路或 proxy 擋住連線、下載到的內容不是行事曆、來源異常）：取不到資料的年份沒有被改動。可以按「重試」，或按「先用現有資料」繼續使用——這時行事曆維持上次更新的結果，畫面頂部會一直提醒「行事曆未能更新，國定假日可能不是最新」，下次開啟程式會再自動嘗試。
原因會記在程式資料夾旁 data/calendar-sync.log（超過 1 MB 會自動換新檔），可以交給維護者查看。官方還沒公告、又沒更新到的年份（目前是 2028 年起），程式會只把週六、週日當成假日，不會有任何國定假日與補班日。排這些月份前，請先確認電腦連上網路、重新開啟程式一次，或向維護者確認行事曆是否已更新。自動更新不會動你自己改過的日子。

步驟 4　建立人員（「人員維護」分頁）

發佈包如果附有名冊檔，第一次啟動時會把名冊匯入一次，之後不會再匯入。名冊裡沒有的人，要自己新增：

  1. 按「新增人員」。
  2. 填姓名、員編，選身分。身分決定可值的區域類型與額度點數上限。
  3. 按「儲存變更」。
  • 人員離職或暫時不排班，按「停用」。停用不影響歷史值班表。
  • 已經有值班紀錄的人無法刪除，只能停用。
  • 身分組由身分決定，不能直接改。
還沒有任何在職人員時，「排班主表」「變體比較」「不可排班日登記」會顯示「尚未建立人員」，並附一個「前往人員維護」按鈕，先去新增人員就可以了。如果名冊裡的人員全都被停用，畫面會改成「沒有在職人員」，請到「人員維護」把人員恢復在職。

名冊檔的內容與匯入規則：名冊檔是發佈者放在發佈包 roster 資料夾裡的 roster.csv。只有第一次啟動、而且人員表是空的才會匯入，匯入過一次之後就不會再匯入。之後想增減人員，一律在「人員維護」操作，不必改名冊檔。

  • 名冊檔有問題時，這一次不會匯入，程式照常啟動，人員表是空的。原因記在 data 資料夾裡的 roster-import.log（內容不含姓名或員編）。看到這個檔案，請交給維護者處理；名冊檔修好後，下次啟動會再試一次。
  • 如果刪掉整個 data 資料夾重新開始，名冊會再匯入一次。

步驟 5　登記不可排班日（「不可排班日登記」分頁）

  1. 上方切換到要排的月份。
  2. 在表格中，替每個人點選他「絕對不能排」的日期。
  3. 每人每月有天數上限，達到上限要先清掉其他天才能再登記。上限可在右側面板調整。
  4. 看右側的「登記概況」與「可行性預警」。有逐日缺口或整月供需不足，代表登記太多、排不出來，請先處理。
  5. 右側會列出「尚未登記」的人。程式不會通知任何人，求解前請自己逐一確認。

步驟 6　求解並比較變體（「變體比較」分頁）

  1. 在「不可排班日登記」按「帶入求解」，或在「變體比較」按「直接求解」。確認後開始。
  2. 程式會依序求出 3 份候選班表（變體），需要一些時間。畫面會顯示進度，隨時可以中止；中止後，已完成的變體仍然保留。
  3. 每份變體都有立場說明、熱圖與各項指標。比較後挑最合適的一份。
  4. 不滿意可以按「重新求解」。

步驟 7　套用（「變體比較」分頁）

  1. 在選好的變體上按「選定此變體」。
  2. 程式會把它套用成該月的值班表草稿。
整份套用變體只能用在草稿。已發布的月份只能在排班主表逐格修改，不能再整份套用。

步驟 8　微調並檢查違規（「排班主表」分頁）

  1. 排班主表有三種看法：「區域 × 日」「日 × 人」「單日詳表」。
  2. 想改某一格，點一下那一格，可以挑人。候選人清單會告訴你誰不能排、為什麼不能排。
  3. 也可以拖曳兩格互相對調。
  4. 每次修改都會立即存檔，不需要另外按儲存。
  5. 右側會列出違規。標著「硬」的違規必須處理，標「軟」的只是提醒。有硬違規時，違規清單最上方會出現一張深色的摘要卡，告訴你有幾項。
  6. 想重新檢查，按「驗證約束」。
程式對修改很寬鬆：硬約束違規也照收，不會擋你，只是把違規列出來。需要擋的時機是發布、匯出與列印，見下一步。

步驟 9　發布

  1. 確認違規都處理完了，按「發布」。
  2. 若還有硬約束違規，會跳出「仍有硬約束違規」，問你要不要在已知違規的情況下發布。確定了再按「仍要發布」。
  3. 發布成功後，狀態變成「已發布 v1」。之後每重新發布一次，版本號加 1。

發布有兩個作用：宣告這份定案，以及結算月結轉（見下一章）。

有「同一人同一天排在兩個區」的情形時，不能發布，也不能匯出與列印，而且沒有「仍要發布」可選。請先把重複的那一格改掉。

步驟 10　匯出 Excel 或列印

  1. 在排班主表按「匯出 Excel」或「列印」。
  2. 如果還是草稿，程式會問你要「先發布再匯出」（或列印）、「直接匯出草稿」還是取消。
  3. 匯出時會跳出存檔視窗，請選要存放的位置。
  4. 列印是 A4 橫式，一頁一個月。列印目前正在看的檢視；單日詳表沒有列印版面，會改印「日 × 人」。

3. 每個月的循環

之後每個月重複步驟 5 到步驟 10 即可（人員、約束與行事曆沒變就不用再看）。

  1. 換到下個月，登記不可排班日。
  2. 求解、套用、微調。
  3. 發布，匯出或列印。
上個月要先發布。發布時才會結算月結轉：上個月比同組其他人多值的額度點數，這個月就讓他少值一點。上個月還沒發布，就先發布這個月的話，這個月的月結轉會固定是空的，之後無法補回。
  • 下個月還是草稿時，月結轉讀的是上個月最近一次發布時結算的結果。上個月發布之後又改了、卻沒有重新發布，改動不會反映進來。
  • 下個月第一次發布時，月結轉會被凍結，之後上個月再怎麼改、再重新發布，這個月已經凍結的月結轉都不會變。

4. 資料在哪裡

所有資料都在程式旁邊的 data 資料夾裡：

  • 人員、值班表、不可排班日、設定，全都存在 data\scheduler.db。
  • 畫面（瀏覽器元件）的暫存也在 data 底下。
  • 程式不會把資料寫到其他地方，例如「文件」或 AppData。唯一的例外是匯出 Excel 時，Windows 自己的存檔視窗會記住你上次選的資料夾，那是 Windows 的行為。

因此，整個資料夾就是你的系統。刪掉 data 資料夾就等於清空所有資料，請小心。

5. 備份

  1. 先關掉程式。
  2. 把整個 data 資料夾複製一份，放到隨身碟或其他安全的地方。可以在資料夾名稱加上日期，例如 data-備份-2026-10-31。

建議每個月發布後備份一次。要還原時，關掉程式，把備份的資料夾改名為 data，取代原本那一個。

6. 換新版

新版本會是另一個 zip，解壓後是另一個資料夾，名稱帶有版本號。舊資料不會自動跟過去，要自己搬 data：

  1. 關掉舊版程式。
  2. 先備份一份舊版的 data（見上一章）。
  3. 把新版 zip 解壓到新的位置（一樣先解除封鎖，見第一章）。
  4. 把新版資料夾裡的 data（如果有的話）刪掉或改名。
  5. 把舊版的 data 整個資料夾搬（或複製）到新版資料夾裡，位置在 HospitalScheduler.exe 旁邊。
  6. 啟動新版。資料庫會自動升級，不用手動做任何事。
  7. 看一下畫面右上角的版本號（視窗太窄時版本號會隱藏，把視窗放大就看得到），並確認人員與值班表都還在。
確認新版一切正常之前，先不要刪舊版資料夾。升級後的 data 不建議再拿回舊版使用。

7. 搬到另一台電腦

  1. 關掉程式。
  2. 把整個程式資料夾（含 data）複製到另一台電腦的可寫入位置，例如隨身碟或桌面。
  3. 在新電腦上連按兩下 HospitalScheduler.exe。
  • 新電腦不需要另外安裝任何東西。
  • 如果是用下載或郵件傳過去的 zip，記得先解除封鎖（見第一章）。
  • 新電腦第一次開啟，同樣可能出現「Windows 已保護您的電腦」，處理方式一樣。

8. 常見問題

啟動時跳出「程式無法啟動」

對話框會寫出原因與程式所在的位置，並提醒：請確認 data 可寫入，或把整個資料夾搬到可寫入的位置後再試。

  1. 最常見的原因是程式放在唯讀或受保護的位置（例如 C:\Program Files\、光碟、唯讀的網路磁碟）。
  2. 把整個資料夾複製到桌面或 D:\ 底下，再啟動一次。
  3. 還是不行，把對話框上的文字抄下來給負責維護的人。

按「發布」跳出「仍有硬約束違規」

代表值班表還有違反硬約束的地方。有兩種做法：

  • 回去右側的違規清單，把違規處理掉，再發布。
  • 如果確定要在已知違規的情況下發布（例如有特殊情形），按「仍要發布」。

發布、匯出、列印被擋住：「還有人同一天排在兩區」

同一個人同一天被排在兩個區域，這個情形沒有任何「仍要」可選，一定要先改掉：

  1. 在排班主表的「日 × 人」檢視找到那一天，該格會同時顯示兩個區域。
  2. 把其中一格改成別人，或對調。
  3. 按「驗證約束」確認違規消失，再發布、匯出或列印。

列印前程式會重新確認一次違規清單；如果確認不了，也會暫時不讓列印，稍後再試即可。

狀態標籤寫著「已發布 v2 · 有修改」是什麼意思？

這份值班表已經發布過，之後又被改過（改格或對調），但還沒有重新發布。

  • 版本號（v2）沒有變，因為版本號只有在發布時才加 1。
  • 目前畫面上的內容，已經不等於當初發布的那一版，已經匯出或印出去的紙本也不會跟著變。
  • 想讓大家拿到最新內容，請按「重新發布」。匯出或列印時，程式也會先問你要不要重新發布。

修改已發布的值班表時，程式會先問一次「修改已發布的值班表」，確定才會改。

找不到求解按鈕，或按了沒反應

求解的按鈕有「帶入求解」（不可排班日登記）、「直接求解」與「重新求解」（變體比較），排班主表上也有「重新求解」。

  • 沒有在職人員時：「不可排班日登記」與「變體比較」不會顯示求解按鈕，排班主表的「重新求解」會變灰。請先到「人員維護」新增人員，或把停用的人員恢復在職。
  • 已經有一個求解在進行時：同一時間只能跑一個，再按求解會帶你去看正在跑的那一份。

求解跑很久

求解需要一些時間，過程中畫面不會凍結，可以隨時按中止。中止後已完成的變體仍可套用。 登記的不可排班日太多會讓問題變難，先看「可行性預警」有沒有缺口。

額度點數值班負擔的計量：平日班 1 點、假日班 2 點。每個身分有硬上限，不能超過。
公平性點數只用來讓大家盡量公平的另一套計量，沒有上限。
假日週六、週日與國定假日的總稱。決定額度點數算 1 點或 2 點，也決定公平性點數查哪一列。
國定假日日曆上的法定假日，不含一般的週六與週日。只用在「連值兩個週六」的加分規則。
補班日因連假調移而要上班的週六，視為平日，額度點數算 1 點。
月結轉上個月比同組其他人多值的額度點數，發布時結算，讓下個月少值一點。
